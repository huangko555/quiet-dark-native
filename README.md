# Quiet Dark Native 2026 Blue

独立的 VS Code 深色主题。界面采用最初 Panda Theme 的原始定义，把亮青绿色 #19F9D8 替换为“深色+（Dark+）”的强调蓝 #007ACC。文档正文、语法、语义着色，以及编辑光标和文字选中背景，均采用内置“2026 深色”的对应颜色。除下述调整外，其余界面背景、边框和透明度保留 Panda 原版。

## 安装

当前版本：**1.0.27**。

1. 使用仓库中的 [dist/quiet-dark-native-1.0.27.vsix](dist/quiet-dark-native-1.0.27.vsix) 安装包。在 GitHub 文件页点击下载按钮，将文件保存到本机。
2. 打开 VS Code 扩展面板右上角菜单，选择“从 VSIX 安装”。
3. 安装后，在颜色主题列表选择 **Quiet Dark Native 2026 Blue**。

也可以在仓库目录执行：

```powershell
code --install-extension .\dist\quiet-dark-native-1.0.27.vsix --force
```

主题已包含完整颜色定义，不依赖 Panda 或其他主题扩展，无需复制个人 settings.json。已有的全局颜色自定义可能覆盖主题的对应颜色。

## 配色

顶部标题栏背景为 #222223；标签栏、未选中标签页及文件路径（面包屑）栏的背景为 #242526，窗口失焦时也保持相应颜色。

普通界面文字采用深色+的灰白色 #CCCCCC；命令面板当前项采用 #0E639C 背景，菜单选中项采用 #04395E 背景，两者均使用白色文字。

活动栏计数徽标和其他通用计数徽标的文字，统一采用深色+的 #FFFFFF。

按钮及扩展安装按钮的背景采用深色+的 #0E639C，悬停背景为 #1177BB；活动栏徽标背景为 #007ACC，通用计数徽标背景为 #4D4D4D。

加载进度条采用深色+的蓝色 #0E70C0。

引用提示文字（CodeLens）采用“2026 深色”的 #8C8C8C，标尺为 #848484；搜索匹配、选中词语及读写位置高亮均采用该主题的蓝灰色和对应透明度。括号匹配使用蓝色背景和深色+的 #007ACC 边框。

自动补全选中项采用与菜单一致的 #04395E 深蓝背景和白色文字、图标；调试状态栏采用与按钮一致的 #0E639C 深蓝背景和白色文字。

终端光标采用“2026 深色”的 #BFBFBF，块光标覆盖的文字采用 #191A1B；这些定义包含在主题中，不依赖本机设置。Git 新增、警告、错误和终端 ANSI 色保留各自的状态含义。

当前标签页和侧边栏选中文件的文字统一使用 #EDEDED；窗口失焦及列表焦点状态也使用相同文字色。

当前标签页背景为 #323334，侧边栏选中文件背景为 #363738；未选中标签页和侧边栏列表的悬停背景为 #303132，当前标签页悬停背景为 #363738，支持现代标签栏。VS Code 原生列表仅对未选中、未聚焦行应用悬停色。

错误提示、删除操作和删除差异标记采用 Dark+ 的内置深色默认配色，主错误色为 #F48771，移除 Panda 原有的品红色覆盖。

## 修改与打包

主题源码位于 [themes/quiet-dark-native-color-theme.json](themes/quiet-dark-native-color-theme.json)。`colors` 控制界面和交互颜色，`tokenColors` 和 `semanticTokenColors` 控制文档语法着色。

修改配色后，在仓库根目录运行以下命令。需要 Python 3.9 或更新版本，无需安装第三方包，也不需要安装 Panda。

```powershell
python scripts/package_theme.py
```

打包脚本读取 `package.json` 中的版本号，将安装包写入 `dist/`，并检查包内主题与源码一致。发布新版本时，先更新 `package.json` 的 `version`，并同步此处的安装包链接。脚本只打包主题、扩展元数据、说明和来源声明。

此版本包含“2026 深色”的配色快照，不会随本机内置主题更新而自动改变。
